# AI Agent Configuration for Purchase Microservice

> Configuration and capabilities for AI-assisted development.

## 🤖 Agent Capabilities

### Code Understanding
- **Spring Boot**: Controllers, Services, Repositories, dependency injection
- **Java 17**: Records, sealed classes, pattern matching, new features
- **JPA/Hibernate**: Entity mapping, query methods, relationships
- **Maven**: Project structure, dependencies, plugins, build lifecycle
- **REST API Design**: HTTP methods, status codes, request/response models

### Development Tasks Agent Can Perform

✅ **Can Help With**:
- Creating REST controllers with proper HTTP mappings
- Implementing Service layer with business logic
- Writing JPA Repository queries
- Creating entity models with relationships
- Building DTOs for API contracts
- Implementing global exception handlers
- Writing integration tests with Spring Test
- Configuring application properties
- Adding health checks and metrics
- Database schema design and migrations

❌ **Not Recommended**:
- Changes to entity structure without migration strategy
- Direct database access from controllers
- Bypassing service layer validation
- Hardcoding configuration values
- Making breaking API changes without versioning

## 🛠 Recommended Skills

### Skill 1: Creating REST Endpoints
**When**: Adding new API resources (Orders, Payments)
**Process**:
1. Create @Entity model with JPA annotations
2. Create Repository extending JpaRepository
3. Create @Service with business logic
4. Create DTO for request/response
5. Create @RestController with mappings
6. Add @ControllerAdvice for error handling

### Skill 2: Service Layer Implementation
**When**: Implementing business logic
**Process**:
1. Inject Repository via @Autowired
2. Implement validation in service methods
3. Use @Transactional for database operations
4. Handle exceptions and throw custom exceptions
5. Return DTOs instead of entities

### Skill 3: Integration Testing
**When**: Testing service and repository layers
**Process**:
1. Use @SpringBootTest for application context
2. Mock dependencies with @MockBean
3. Test service methods with test data
4. Verify database interactions
5. Test error scenarios

## 🔑 Key Concepts

- **Layered Architecture**: Clean separation of concerns
- **Dependency Injection**: Spring's @Component, @Service, @Repository
- **JPA Relationships**: OneToMany, ManyToOne, OneToOne
- **Transaction Management**: @Transactional for ACID operations
- **REST Conventions**: Proper HTTP methods and status codes

## 📁 File References

- Controllers: `src/main/java/.../controller/`
- Services: `src/main/java/.../service/`
- Repositories: `src/main/java/.../repository/`
- Entities: `src/main/java/.../model/`
- DTOs: `src/main/java/.../dto/`
- Configuration: `src/main/resources/application.yml`
